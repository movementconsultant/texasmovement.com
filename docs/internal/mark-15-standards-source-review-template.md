# Mark 15 (internal) — Standards Source-Review Template

Internal-only. Not rendered, not imported, not linked from any public route.
A reusable intake form for any future external standard, law, regulation,
guideline, or policy someone proposes as an internal reference. **No source
has been researched, located, retrieved, or filled into this template in
this pass** — it is blank scaffolding only, consistent with the parent
brief's prohibition on external research or source retrieval in this task.

Copy this template once per candidate source. Do not adopt, cite, or act on
any source until every field is completed and an owner decision is
recorded.

## Usage notes

- One template per source. Do not bundle multiple sources into one review —
  each has its own date, jurisdiction, and limitations.
- A source touching the restricted domains (tensegrity-as-therapy, athlete
  therapy, or Health/clinical content — matrix items 3 and 4) requires
  licensed-professional review *in addition to* legal review before its
  "internal adoption recommendation" field may read anything other than
  `hold for review` or `reject`.
- Completing this template does not authorize public use of the source in
  any form. It only supports an internal decision about whether and how to
  reference the source *internally*. A separate, later, explicitly
  authorized task is required before any public wording tied to this
  source is drafted.
- This template does not fetch, browse, or verify any external URL by
  itself — completing it is a manual, human research and documentation
  step, not an automated one.

# Mark 8 TMM Source Verification Checklist

**PRIVATE. INTERNAL ONLY. NOT RENDERED. NOT PUBLIC CONTENT.**

**Do not publish or link until approved.** This is an owner-facing checklist for verifying any
potential TMI, TMM, or AVM/founder media source before it can be displayed anywhere. Every item
below defaults to unconfirmed. **External platform behavior may change** — a checklist completed
today does not guarantee the same platform, URL, or account behaves identically tomorrow;
revalidate on the schedule set at the bottom of this document. **No automatic cross-posting or
cross-attribution** occurs as a result of completing this checklist — see the attribution policy
in `docs/internal/mark-8-tmm-unified-media-feed-architecture.md` Part B.

Complete one copy of this checklist per source account or per item, as appropriate. Mark each line
**"Owner-provided"** or **"Not independently verified"** — never leave a line unmarked, and never
substitute an assumption for either label.

---

## Reminders

- **Owner-provided** means the owner (or an explicitly named delegate) supplied the information —
  it does not by itself mean independently confirmed.
- **Not independently verified** is the correct default for every line until real evidence closes
  it — leaving a line at this default is not a failure, it is the honest state.
- **Do not publish or link until approved** applies to every line on this checklist, not only the
  ones that mention it explicitly.
- **External platform behavior may change** — treat every "Approved" disposition as time-bound,
  not permanent, and revalidate on schedule.
- **No automatic cross-posting or cross-attribution** — completing this checklist for one platform
  or one attribution class never extends to another without its own separate approval.
